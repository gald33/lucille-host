# What the build removes from the pinned Python runtime: one literal path per line, relative to
# the archive's top folder `python/`. Reviewed like code. build_app.py refuses a path that the
# pinned runtime does not hold, a pattern, a path with . or .., a *.dist-info folder or anything
# in one, and anything in site-packages but README.txt. The runtime's own pip is not listed: the
# build uninstalls it whole, by its RECORD, before pruning (that removes bin/pip, bin/pip3 and
# bin/pip3.13 too). Whatever this list misses is not deleted: the build refuses a runtime that is
# not then exactly bin/lucille-host-runtime and lib/python3.13/, with an empty site-packages.
#
# CI runs the host's whole test suite on a copy of the pruned runtime, so a wrong cut fails a
# pull request.

# Programs the app never runs. The interpreter, bin/python3.13, is kept and renamed
# lucille-host-runtime; bin/python and bin/python3 are links to it.

bin/pydoc3.13
bin/python
bin/python3
